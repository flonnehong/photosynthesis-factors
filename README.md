# 광합성에 영향을 주는 요인 — 1차시 탐구 수업 자료

중학교 2학년 과학 **Ⅴ. 식물과 에너지 — 광합성** 단원 중 「광합성에 영향을 주는 요인」을 1차시(45분) 동안 수업할 수 있는 HTML 자료입니다.
설치 없이 브라우저에서 바로 열 수 있고, 휴대폰·태블릿·크롬북에서도 사용할 수 있습니다.

## 구성

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 생각 열기 | 5분 | 핵심 질문: "비닐하우스에서 딸기가 광합성을 더 많이 하게 하려면?" |
| ② 실험 설계 | 7분 | 검정말 실험 장치 이해, 조작·종속·통제 변인 구분하기 |
| ③ 가상 실험 | 18분 | 검정말 가상 실험실 — 빛의 세기(전등 거리), 이산화 탄소 농도(탄산수소 나트륨), 온도를 바꾸며 1분 동안 기포 수 측정 → 결과표·그래프 자동 작성 |
| ④ 결과 해석 | 7분 | 세 그래프 비교, 경향 곡선 확인, 개념 정리 |
| ⑤ 확인 문제 | 6분 | 6문항 자기 점검 |
| ⑥ 정리 | 2분 | 핵심 질문에 근거를 들어 답하기 |

## 특징

- 측정하는 동안 조건을 바꾸면 측정이 취소되고, 통제 변인이 첫 측정과 다르면 경고가 표시되어 **변인 통제**를 자연스럽게 연습할 수 있습니다.
- 측정값에는 실제 실험처럼 약간의 오차가 있습니다.

## 사용 방법

- 온라인: GitHub Pages 주소로 접속
- 오프라인: `index.html` 파일을 내려받아 브라우저로 열기

학생이 적은 내용과 실험 기록은 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다.
